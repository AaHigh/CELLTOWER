## What It Is

CELLTOWER is a single-file (`index.html`) NES-accurate competitive Tetris trainer targeting iPhone Safari. No dependencies, no build step — push to GitHub Pages and it's live. Cash-prize skill-based tournaments are the end goal, structured under California's dominant factor test (Penal Code §330, AB 831). Full legal analysis in `verification.md`.

## What Got Built This Month

### Cryptographic Score Verification (Phase 1)
- SHA-256 hash chain starting from a random 16-byte seed committed before each game
- Hash advances on every piece lock: `Hₙ = SHA-256(Hₙ₋₁ ‖ 5-byte placement record)`
- 5-character base-40 receipt code (`G.receiptCode`) displayed live and on the receipt
- Receipt button gated: only accessible when paused or game over — no accidental taps during play
- AI-played games suppress the hash chain and receipt code entirely — no valid verification for auto scores

### Verification Stripe (Visual History Tape)
The right edge of the playfield carries a live history tape that records every piece placement as a colored block:

- **Piece colors**: I=cyan, O=yellow, T=purple, S=green, Z=red, J=blue, L=orange
- **Dot encoding**: a single black dot within each block encodes which of the 4 placement slots was chosen. Position is symmetric: slots 1 and 4 are mirrored about center, slots 2 and 3 are mirrored closer in. Formula: `pos = round(slot * (w-1) / 3)`
- **Routing**: counter-clockwise around the playfield — right side up → top across → left side down → bottom across. One full revolution targets ~270 pieces (kill screen range)
- **Unlimited history**: when the first revolution fills, new columns grow outward on the right and left sides alternately, each separated by a 1px black gap. Top and bottom are used once only. Block size never changes
- **Human vs. AI**: human play infers slot from the closest ghost placement to where the piece landed. Auto play uses a random 0–3 (decorative only)

### Kill Screen at Level 20
- Game locks at level 20 — no infinite play past authentic NES kill screen range
- 2.5-second rainbow board corruption animation (`drawKillScreen`)
- Game-over overlay shows "KILL SCREEN / LVL 20" header instead of "GAME OVER"

### UI Polish
- **PAUSE button**: when paused, shows "RESUME" with blinking green text and a ▶ symbol at 75% white
- **Piece preview scaling**: all 4 ghost placement buttons compute a single uniform scale from the smallest fitting piece — no more mismatched sizes across slots
- **VAN NESS & OLIVE**: corrected from a speech-to-text error in the receipt footer

## Architecture Snapshot

```
index.html (~6200 lines, single file, no dependencies)
  ├── setupDOMStubs()         — bridges legacy DOM writes to globals
  ├── const G                 — single object aliasing 60+ globals via defineProperty
  ├── _hashChainBuf / _chainPromise — async SHA-256 chain, serial via promise chaining
  ├── _gameHistory[]          — [{k, slot}] per locked piece, drives the stripe
  ├── drawVerificationStripe  — unlimited outward-expanding lane routing
  ├── drawKillScreen          — rainbow corruption animation
  └── buildReceiptDOM         — printable verification receipt
```

## Legal Foundation

The tournament structure targets California's dominant factor test. Key points:

- Tetris is skill-dominant: same top players win consistently, skill differentials are enormous (novice < 100K, elite > 1M)
- AB 831 (effective Jan 1, 2026) targets dual-currency casino-simulation platforms — CELLTOWER is none of that
- The verification system makes every aspect transparent and auditable: provably fair seed, open-source physics, tamper-evident replay
- No house edge, no banking game — entry fees fund a peer-to-peer prize pool

Full argument: `verification.md`
